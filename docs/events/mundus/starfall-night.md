## 概述

星陨之夜是本世界纪元的开端。那一夜，天穹的星辰坠落大地，[星辉](/glossary/mundus/starlight)之力涌入世间，也烧出了[灰烬荒原](/locations/mundus/ashen-wastes)。

## 经过

1. 星辰坠于大陆东南，千里沃野化为焦土；
2. 幸存者在废墟上建立[银辉城](/locations/mundus/silverlight-city)与[银辉王国](/factions/mundus/silverlight-kingdom)；
3. [星语教团](/factions/mundus/starwhisper-order)兴起，宣称星辉是世界的馈赠；
4. 「星历」纪年自此启用。

## 影响

- 世界进入星辉时代，魔法成为可能；
- [陨星之刃](/items/mundus/meteor-blade)等遗物现世；
- 星陨的**真正原因**至今成谜（见[灰烬荒原](/locations/mundus/ashen-wastes)的待整理项）。
